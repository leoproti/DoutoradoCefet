Dados: $F_0=10\,000$, $E_0=5\,000$, $\lambda_F=0{,}1$/dia.
O critério de vitória de Lanchester é $\lambda_F F_0^2 > \lambda_E E_0^2$:
\[
\lambda_F F_0^2 = 0{,}1\times10\,000^2 = 10^7.
\]
\begin{itemize}
\item \textbf{$\lambda_E=0{,}2$}: $\lambda_E E_0^2 = 0{,}2\times5\,000^2=5\times10^6 < 10^7$. Vence $F$.
\[
F_f = \sqrt{F_0^2 - \frac{\lambda_E}{\lambda_F}E_0^2} = \sqrt{10^8 - 2\times25\times10^6} = \sqrt{5\times10^7} \approx 7\,071\ \text{soldados}.
\]
\item \textbf{$\lambda_E=0{,}5$}: $\lambda_E E_0^2 = 1{,}25\times10^7 > 10^7$. Vence $E$.
\[
E_f = \sqrt{E_0^2 - \frac{\lambda_F}{\lambda_E}F_0^2} = \sqrt{25\times10^6 - 0{,}2\times10^8} = \sqrt{5\times10^6} \approx 2\,236\ \text{soldados}.
\]
\item \textbf{$\lambda_E=1{,}0$}: $\lambda_E E_0^2 = 2{,}5\times10^7 > 10^7$. Vence $E$.
\[
E_f = \sqrt{E_0^2 - \frac{\lambda_F}{\lambda_E}F_0^2} = \sqrt{25\times10^6 - 0{,}1\times10^8} = \sqrt{1{,}5\times10^7} \approx 3\,873\ \text{soldados}.
\]
\end{itemize}
O empate ocorre quando $\lambda_F F_0^2 = \lambda_E E_0^2$, ou seja,
\[
\lambda_E = \lambda_F\left(\frac{F_0}{E_0}\right)^{2} = 0{,}1\times\left(\frac{10\,000}{5\,000}\right)^{2} = 0{,}1\times4 = 0{,}4\ \text{dia}^{-1}.
\]
