\textbf{Comparação das séries:}

\[
\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots = x - \frac{x^3}{6} + \frac{x^5}{120} - \cdots
\]
\[
\tan x = x + \frac{x^3}{3} + \frac{2x^5}{15} + \cdots
\]

Aproximando pelo primeiro termo: $\sin x \approx x$ e $\tan x \approx x$. \textbf{Sim, são semelhantes para $|x|\ll1$}.

\textbf{Diferença relativa (erro em $\sin x \approx x$):}
\[
\frac{\sin x - x}{x}\approx -\frac{x^2}{6}.
\]

\textbf{Diferença relativa (erro em $\tan x \approx x$):}
\[
\frac{\tan x - x}{x}\approx +\frac{x^2}{3}.
\]

O erro em $\tan x$ é \emph{o dobro} do erro em $\sin x$ e tem sinal oposto.

\textbf{Conclusão:} para $x\leq0{,}1$ rad ($\approx5{,}7$\textdegree) ambas as aproximações são excelentes (erro $<0{,}2\%$). Para $x>0{,}5$ rad, $\tan x$ diverge rapidamente de $x$, enquanto $\sin x\approx x$ ainda é razoável.
