A eq.~(4.6) é a série de Taylor de $\cos x$:
\[
\cos x = 1 - \frac{x^{2}}{2!} + \frac{x^{4}}{4!} - \frac{x^{6}}{6!} + \cdots \quad \text{(eq.~4.6)}.
\]

\textbf{Substituição $x \to ix$:}

Aplicando $x \mapsto ix$ com $i=\sqrt{-1}$, calcula-se cada potência:
\[
(ix)^1=ix,\quad (ix)^2=i^2x^2=-x^2,\quad (ix)^3=i^3x^3=-ix^3,
\]
\[
(ix)^4=i^4x^4=x^4,\quad (ix)^5=ix^5,\quad (ix)^6=i^6x^6=-x^6,\ldots
\]

Portanto:
\[
\cos(ix) = 1 - \frac{(ix)^{2}}{2!} + \frac{(ix)^{4}}{4!} - \frac{(ix)^{6}}{6!} + \cdots
= 1 - \frac{-x^{2}}{2!} + \frac{x^{4}}{4!} - \frac{-x^{6}}{6!} + \cdots
\]
\[
= 1 + \frac{x^{2}}{2!} + \frac{x^{4}}{4!} + \frac{x^{6}}{6!} + \cdots
\]

Mas a definição da função cosseno hiperbólico é:
\[
\cosh x = \frac{e^x+e^{-x}}{2} = 1 + \frac{x^{2}}{2!} + \frac{x^{4}}{4!} + \frac{x^{6}}{6!} + \cdots \quad \text{(eq.~4.7)}.
\]

\textbf{Conclusão:} as duas séries coincidem, portanto:
\[
\boxed{\cos(ix) = \cosh x.}\quad\blacksquare
\]

De forma análoga, substituindo $x\to ix$ na série de $\sin x$:
\[
\sin(ix) = ix + \frac{(ix)^3}{3!} + \cdots = ix - \frac{ix^3}{3!}+\cdots = i\left(x+\frac{x^3}{3!}+\cdots\right) = i\sinh x.
\]
