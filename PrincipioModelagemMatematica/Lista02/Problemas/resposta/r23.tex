Os intervalos correspondem a metade da unidade da ultima casa significativa:
\begin{align*}
(a)\;&7.7 \Rightarrow 7.65 \le x < 7.75, \\
(b)\;&7.70 \Rightarrow 7.695 \le x < 7.705, \\
(c)\;&1200 \Rightarrow 1150 \le x < 1250,
\end{align*}
se a ultima casa significativa for a das centenas. Alem disso,
\[
(d)\quad 1.1995\times 10^{-3} \le x < 1.2005\times 10^{-3}
\]
para o valor $1.200\times 10^{-3}$.
No item (c), ha ambiguidade se o numero nao for escrito em notacao cientifica.
