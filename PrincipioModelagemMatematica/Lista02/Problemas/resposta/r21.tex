O enunciado resumido nao traz os fatores numericos a serem multiplicados, entao nao ha como fechar os resultados finais. Ainda assim, a regra correta para multiplicacao com algarismos significativos e:
\[
\text{o produto deve ter tantas cifras significativas quanto o fator menos preciso.}
\]
Portanto, a resolucao do problema 4.19 consiste em:
\begin{enumerate}
\item efetuar cada multiplicacao com todos os digitos disponiveis;
\item identificar o operando com menor numero de cifras significativas;
\item arredondar o produto final para esse mesmo numero de cifras.
\end{enumerate}
Sem os operandos completos, essa e a resposta tecnicamente correta.
