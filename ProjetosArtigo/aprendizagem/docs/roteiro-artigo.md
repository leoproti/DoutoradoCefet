# Roteiro de Artigo Cientifico

## 1. Titulo provisiorio

Use uma estrutura objetiva:

Efeito de X sobre Y no setor agropecuario: evidencia para [regiao] entre [periodo inicial] e [periodo final]

## 2. Problema de pesquisa

Defina em uma frase:

- qual variavel voce quer explicar;
- qual fator principal pode influenciar esse resultado;
- qual o recorte geografico e temporal.

## 3. Hipotese

Exemplo:

Maior acesso ao credito rural esta associado a maior produtividade agricola municipal.

## 4. Justificativa

Responda:

- por que esse tema importa economicamente;
- qual lacuna da literatura ou da evidencia aplicada sera explorada;
- por que os dados permitem uma contribuicao relevante.

## 5. Dados e variaveis

Monte uma tabela minima contendo:

- variavel dependente;
- variavel explicativa principal;
- variaveis de controle;
- fonte de cada dado;
- unidade de medida.

## 6. Estrategia empirica

Comece com o basico:

- estatistica descritiva;
- correlacoes;
- comparacoes entre grupos;
- regressao linear simples ou multipla.

## 7. Resultados

Organize em tres blocos:

- perfil da base de dados;
- resultados principais;
- interpretacao economica dos achados.

## 8. Discussao

Explique:

- o que o resultado significa para o setor;
- quais mecanismos podem explicar o efeito observado;
- quais sao as limitacoes do estudo.

## 9. Conclusao

Feche com:

- resposta objetiva a pergunta de pesquisa;
- implicacoes para gestao, politica publica ou mercado;
- agenda de pesquisa futura.

## 10. Estrutura minima do resumo

Modelo:

Este estudo analisa [tema] no setor agropecuario de [recorte]. Utilizando dados de [fontes] para o periodo de [anos], investigamos [objetivo]. Os resultados indicam [achado principal]. As evidencias sugerem [implicacao].
